## このアプリが生み出す価値

お客様は、**注文してからお店に向かい、取りに行くだけ**で商品を受け取れます。スマホの画面で「あと何杯待ちか」「あと何分でできあがるか」がリアルタイムに見えるので、店頭に並んで待つ必要がありません。

お店側にとっては、レジ前の行列そのものが無くなることで、ピーク時の混雑や「並ぶのが嫌で帰ってしまうお客様」を防ぎ、スタッフは列整理ではなく製造作業に集中できます。

## 1. これは何のアプリか

お客様がスマートフォンで注文し、お店に着いたときには商品ができあがっている、という体験を作るためのアプリです。

- 専用アプリのインストールは不要。Webページとして使う
- 支払いはアプリ内決済に対応しています。注文を確定するタイミングで事前にお支払いいただきます。**現時点では決済事業者（PayPay）との正式契約手続きがまだ完了していないため、実際の課金はまだ始まっておらず、テスト運用中です**。契約が完了次第、実際の課金を開始します
- お店には製造用の機械が4台あり、それぞれ担当する飲み物が決まっている（詳しくは[§4](#4-商品ができるまでの流れゾーンという考え方)）
- 完成した商品は自動搬送レーンで店内中央の受け渡し場所（提供台）まで運ばれ、既存の自動受渡システムがお客様の受け取りを検知する（詳しくは[§3](#3-スタッフの使い方)・[§9](#9-かんたん用語集)）

## 2. お客様の使い方

1. Webページを開く
2. メニューから商品を選ぶ（ホット/アイス・サイズ・個数を選べる）
3. カートに入れて注文を確定し、その場でお支払いを行う（アプリ内決済。現時点ではテスト運用中につき実際の課金は発生しません。[§1](#1-これは何のアプリか)参照）
4. お支払いが確認できると注文が受け付けられ、注文番号が表示される
5. 「あと何杯待ちか」「あとどれくらいで受け取れるか」がスマホの画面で確認できる
6. 「できあがりました」の表示が出たら商品を受け取る

ログインや会員登録は不要です。お客様の識別は、スマホの中に一時的に保存される目印（セッションID）で行います。

## 3. スタッフの使い方

1. タブレットで専用ページを開き、共有アカウント（ユーザー名とパスワード）でログインする（Googleアカウント等の外部連携はしていません。IDとパスワードは開発側が発行します）
2. 自分が担当するゾーン（A/B/C/Dのいずれか。[§4](#4-商品ができるまでの流れゾーンという考え方)参照）を選ぶ
3. 自分のゾーンに割り当てられた注文だけが、カードの形で一覧表示される
4. カードを右にスワイプすると「製造開始」
5. 完成したらスワイプで「完成」を伝える
6. 誤操作防止のため、スワイプ後3秒間は取り消しボタンが表示されます。3秒が経過すると取り消しができなくなり、ステータスが正式に更新されます（手順4のスワイプなら「製造中」へ、手順5のスワイプなら「完成」へ）。**現場では忙しい時間帯ほど誤ってスワイプしてしまいがちですが、この3秒間の猶予があることで、誤操作による手戻りを防げます**
7. 完成した商品は自動搬送レーンに乗せ、店内中央の提供台まで運ぶ。提供台の「提供ボタン」を押し、電子パネルが示す位置に商品を置く

最大4台のタブレットが同時にログインでき、各ゾーンに1台ずつ配置することを想定しています。専用の「受け渡し担当」というスタッフ役はいません。

> **受け渡しの確認は自動で行われます**。お客様が商品を持ち去ると、提供台に設置された既存の自動受渡システム（電子パネル＋検知カメラ）がそれを検知し、「受渡完了」を自動的に確定します。スタッフが受け渡しを確認するボタンを押す作業は発生しません（[§5](#5-複数の商品を一度に注文したときのできあがりましたの出し方)で詳しく説明）。
>
> なお、この自動搬送レーン・電子パネル・検知カメラは、アプリ本体とは別に店舗側で用意する物理的な設備です。導入・運用にはアプリのAWS利用料とは別の費用がかかります。

## 4. 商品ができるまでの流れ（ゾーンという考え方）

お店には製造機械が4台あり、それぞれ「どの飲み物を、どのサイズまで作れるか」が決まっています。これを「ゾーン」と呼びます。

| ゾーン | 作る商品 | サイズ |
| --- | --- | --- |
| ゾーンA | エスプレッソ系 | Lサイズのみ |
| ゾーンB | エスプレッソ系 | Mサイズのみ |
| ゾーンC | エスプレッソ系 | Sサイズのみ |
| ゾーンD | エスプレッソを使わない飲み物（お茶・フラペチーノ等） | S/Mサイズ |

注文が入ると、商品ごとに自動的に担当ゾーンへ振り分けられます。1つの注文に複数の商品が入っている場合、商品ごとに違うゾーンへ振り分けられることがあります（これが次の章のテーマです）。

## 5. 複数の商品を一度に注文したときの「できあがりました」の出し方

ここが一番間違えやすいポイントなので、具体例で説明します。

### 具体例

お客様がラテ（Lサイズ）とお茶（Mサイズ）を1回のお会計でまとめて注文したとします。

- ラテ → ゾーンA（エスプレッソ用マシン）で作る
- お茶 → ゾーンD（エスプレッソを使わないマシン）で作る

この2つは**別々の機械で、別々のタイミングで作られます**。ゾーンAが先に終わることもあれば、ゾーンDが先に終わることもあります。

### 「できあがりました」はいつ出すか

**注文に含まれる商品が全部そろった瞬間**に、お客様へ「できあがりました、受け取れます」を表示します。

たとえゾーンAのラテが先に完成しても、ゾーンDのお茶がまだなら、画面には「製造中」の表示のままにします。ラテだけできた段階でお客様に通知を出してしまうと、お客様が早くお店に来てしまい、結局お茶ができるまでカウンターで待つことになってしまうためです。

これは、レストランで「お料理は1品ずつ出さず、注文いただいた分が全部そろってから一緒にお出しする」のと同じ考え方です。

### タイムラインで見ると

| 時刻 | ゾーンA（ラテ） | ゾーンD（お茶） | お客様への表示 |
| --- | --- | --- | --- |
| 12:00 | 順番待ち | 順番待ち | 受付済み |
| 12:02 | 製造中 | 順番待ち | 製造中 |
| 12:04 | **完成** | 製造中 | 製造中（お茶待ち） |
| 12:07 | 完成 | **完成** | **できあがりました** ← ここで初めて通知 |

### 受け渡しも「まとめて1回」

商品ができあがったら、ラテとお茶を別々に渡すのではなく、**そろった商品をまとめて提供台に並べ、1回でお渡しします**。片方だけ先に渡してしまうと、後で「お茶を渡し忘れた」という事故につながるためです。受け渡し自体は、既存の自動受渡システム（電子パネル＋検知カメラ）がお客様の持ち去りを検知して確定します（詳しくは[§3](#3-スタッフの使い方)）。

## 6. キャンセルについて

お客様がご自身でキャンセルできるのは、**注文したすべての商品が「まだどのゾーンでも作り始めていない」間だけ**です。

1つでも商品が製造中に入ったら、その注文はもうキャンセルできません（作りかけの商品が無駄になってしまうため）。

> **現時点での制限**: 今のところ、スタッフ側から注文をキャンセルする機能はありません。作り間違いやお客様が受け取りに来ない場合の対応は、当面レジでの手作業になります。この機能は将来追加する予定です（[§8](#8-今のところ入っていない機能今後追加予定)参照）。

---

## 7. 受付を一時的に止めたいとき

営業時間外や、注文が集中しすぎてさばききれないときのために、**スタッフ画面から注文の受付をオン・オフで切り替えられる機能**を検討しています。

- オフにしている間は、お客様のメニュー画面に「ただいま受付を停止しています」と表示され、新しい注文はできなくなる、という機能を想定しています
- 難しい設定は不要で、ボタン1つで切り替えられるようにしたい考えですが、**現時点ではまだ着手時期が決まっていません**（アイデア段階です）

## 8. 今のところ入っていない機能（今後追加予定）

以下は最初のバージョンには含まれませんが、将来追加を検討している機能です。

| 機能 | 内容 |
| --- | --- |
| スタッフ側キャンセル機能 | 作り間違い・受け取りに来ないお客様の注文をスタッフが取り消せるようにする |
| 受取時刻の指定 | 「〇時に取りに行きたい」という予約注文への対応 |
| 個人ごとのスタッフアカウント | 現在は共有の1アカウントのみ |

> アプリ内決済の仕組み自体は実装済みです（[§1](#1-これは何のアプリか)参照）。決済事業者との正式契約が完了し、実際の課金が始まるまでは「本番」扱いではないため、この一覧とは別に記載しています。

## 9. かんたん用語集

| 用語 | かんたんな説明 |
| --- | --- |
| ゾーン | 製造機械1台が担当するエリア（A/B/C/Dの4つ） |
| 明細 | 注文の中の商品1品目のこと。1つの注文に複数の明細（商品）が入ることがある |
| 注文番号 | お客様に表示される、お店で使う短い番号（例: #042） |
| キュー位置 | 自分の前に何人（何杯）待っているかを示す表示 |
| セッションID | お客様のスマホを一時的に識別するための目印。ログインの代わり |
| 自動搬送レーン | 完成した商品を、ゾーンから店内中央の提供台まで自動で運ぶベルトコンベア等の設備 |
| 提供台 | 自動搬送レーンの終点。ここでお客様が商品を受け取る |
| 自動受渡システム | 提供台に設置された既存の外部システム（電子パネル＋検知カメラ）。商品の置き場所を指示し、お客様の持ち去りを自動で検知して受け渡し完了を確定する |
