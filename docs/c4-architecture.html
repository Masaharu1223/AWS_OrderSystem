Level 3 — コンポーネント（order-fn を例に）

各Lambdaは「ハンドラ層 → ドメイン層（純粋関数）」「ハンドラ層 → アダプタ層（DynamoDB等のI/O）」の3層。ドメイン層はAWSに依存せず、アダプタ層を直接呼ばない。
